Plate 0 — Visual identity

Peek LLM design tokens.

The single source of the shared visual identity: a technical-plate language of warm paper, hairline rules, corner-bracket frames, uppercase labels, and serif display type. Shell templates (templates/slides.html, templates/scroll.html, templates/studio.html) and exhibits copy the :root block and base styles from this file. Adapt how hues are used — never the base palette.

Categorical chip hues

Eight curated hues, assigned by position ([174, 210, 36, 152, 262, 348, 24, 300]) so neighbours always contrast. Never hash colors from data IDs.

Type

Three families: sans for UI and prose, serif (--font-serif) for headings and figure captions, mono (--font-mono, with tabular-nums) for data and readings. Weights stay at 600 or below — hierarchy comes from family, size, color, and letterspacing, never from stacking heavier weights.

600 · labels, buttons, readings 500 · dense running data text 400 · prose serif 700 · display headings only serif italic · Fig. captions
